## 七、技术栈总览

| 层级 | 技术 | 版本/配置 |
|------|------|----------|
| 运行时 | Bun | Bun.serve + Bun.file |
| 前端框架 | React 18 | Function Components + Hooks |

| 同步 | BroadcastChannel | 跨标签页状态同步 |
| AI SDK | BigModel (Zhipu) + Ollama | 多服务商切换 |
| PWA | Service Worker | 离线支持 + 安装提示 |
| 文件系统 | File System Access API | 宿主文件读写 |
| 语音 | Web Speech API | 语音控制音乐播放 |
| 测试 | Bun test | 40+ 测试文件 |

## 八、功能拓展建议

### 8.1 短期 (1-2 周)

| 优先级 | 建议 | 说明 |
|--------|------|------|
| 🔴 高 | 多语言扩展 | 当前 zh-CN/en-US，建议增加 ja-JP/ko-KR |

| 🟡 中 | 通知中心 | 统一 toast + 浏览器通知 + 推送通知 |

### 8.2 中期 (1-2 月)

| 优先级 | 建议 | 说明 |
|--------|------|------|
| 🟡 中 | AI Agent 工作流 | MCP 协议已就绪，接入真实 Agent 执行引擎 |
| 🟡 中 | 数据导入/导出增强 | ConfigExportCenter 已路由，增加定时备份 |
| 🟢 低 | 巨型组件拆分 | 6 个 >1000 行组件按需拆分 (Phase AA) |
| 🟢 低 | 测试覆盖率提升 | createLocalStore 测试迁移至 Zustand mock |
