## 五、其他优化项

| 优化项 | 优化前 | 优化后 |
|--------|--------|--------|
| TopBar 搜索框 | 装饰性，无功能 | Focus → 打开 CommandPalette |
| CommandPalette | 28 搜索项 | 32 搜索项 (+4) |
| API Keys 数据源 | family-settings-slice.providerKeys | provider-slice.configuredModels (SSOT) |
| 三端导航数据 | 各自独立定义 (NAV_CATEGORIES/MOBILE_NAV/MORE_CATEGORIES) | 统一为 7 分类一致结构 |
| FamilyModelSettings | API Keys 独立存储 | 统一读写 provider-slice |
