# Guidelines for AI Music Creation Full Closed-Loop Workflow

> **Important Note**: D-Music is a bilingual (Chinese-English) system, with **Chinese** set as the default display language. You can switch the interface language at any time in the settings to suit your preference.

## 1. Pre-Creation: Big Data Positioning & Inspiration Anchoring

### 1.1 Data Insight (Key Operations)
- Navigate to **My** → Review 30-day work data: likes, collections, plays, comment keywords, and audience demographics.
- Identify high-performing style combinations, theme preferences, and audience age/geographic distribution.

### 1.2 Inspiration Anchoring (Prompt Template)
```markdown
【Big Data Creation Anchoring】:
- Core Insight: 30-day data shows the "Jiangnan Elegance + Wandering Folk" style combination has 2.3x more likes than other styles, with a primary audience of 18-25-year-old females who prefer "urban nostalgia" and "healing longing" themes.
- Creative Direction: Next work theme: *Urban Nostalgia*; Style combination: *Jiangnan Elegance + Wandering Folk*; Vocal tone: *Cool female voice*.
- Monetization Expectation: Prioritize for copyright distribution and digital record production.
```

## 7. Social Sharing & Community Distribution

### 7.1 Share Work Card (Key Operations)
- **Entry Points**:
  - **AI Creation Studio** → **My Works** tab → Hover/tap a work → Click **Share** (Share2 icon).
  - The share button is always visible on mobile; reveals on hover on desktop.
- **Share Card Generation**: The system renders a Canvas-based share card containing:
  - Work title, theme badge, creation mode indicator, and lyric preview.
  - Creator name and creation timestamp.
  - D-Music branded gradient background with cosmic visual effects.
- **Distribution Methods**:
  - **Copy Image**: Copies the generated card to the clipboard for pasting into chat apps.
  - **Download**: Saves the card as a PNG file to the device.
  - **Web Share API**: On supported devices, triggers the native OS share sheet for direct sharing to social apps.
- **Backend Integration**: Shared work metadata is persisted via the `/api/shared-works` endpoint for analytics and community feed integration.

### 7.2 Prompt Template
```markdown
[Share Work]:
- Target Work: "Starlight Serenade"
- Share Format: Visual card with lyrics preview
- Distribution: Copy to clipboard, then share to WeChat Moments / Weibo
- Tracking: Record share event for creator analytics dashboard
```

## 8. MV Creator: Audio-Visual Synthesis Engine

### 8.1 Overview
The MV Creator is a real-time Canvas-based music visualization engine that generates animated visual content synchronized to audio energy, frequency spectrum data, and emotional context. It supports five visual themes and provides lyrics overlay, screenshot, and fullscreen capabilities.

### 8.2 Visual Themes
| Theme | Chinese | Description | Color Palette |
|-------|---------|-------------|---------------|
| Starfield | 星空漫游 | Deep space particle field with gravitational drift | Indigo / Purple / White |
| Neon Pulse | 霓虹脉冲 | Pulsating neon energy with glow effects | Magenta / Purple / Blue |
| Aurora | 极光幻境 | Ethereal aurora borealis with soft elliptical particles | Teal / Purple / Pink |
| Ink Wash | 水墨流韵 | Traditional Chinese ink wash with mountain silhouettes | Dark / Light gray |
| Cyber City | 赛博都市 | Cyberpunk rain with perspective grid floor | Cyan / Magenta / Yellow |

### 8.3 Entry Points
- **Desktop Header**: Click the **Film** icon in the top navigation bar to open MV Creator with the currently playing track.
- **AI Creation Studio Hub**: Click the **MV Creator** mode card (marked with an external link icon to indicate it opens a separate full-screen panel rather than an inline sub-mode).
- **My Works List**: Click the **Film** button on any saved work to open the **"Create MV from this work"** flow, which pre-loads the work's lyrics into the MV Creator for synchronized overlay display.

### 8.4 Create MV from Work (Lyrics Pre-loading Flow)
When triggered from a saved work in the My Works list:
1. The work's lyrics array is passed via `onOpenMV(work.lyrics)` to the parent App.
2. App stores the lyrics in `mvCustomLyrics` state and opens the MV Creator.
3. MVCreator receives `customLyrics` prop and generates synthetic timed lyric lines, evenly distributing them across the track's duration.
4. The lyrics overlay on the Canvas uses these pre-loaded lines instead of the current track's embedded lyrics.
5. A **"Work Lyrics"** badge appears in the MV Creator header to indicate custom lyrics are active.
6. When the MV Creator is closed, `mvCustomLyrics` is cleared, restoring default behavior.

### 8.5 Canvas Rendering Pipeline
```
Background (theme-specific) → Particle System (energy-reactive) → Frequency Spectrum Bars → Center Energy Ring → Lyrics Overlay (with glow/shadow) → Track Info Overlay → Progress Bar
```

- Theme: Neon Pulse (霓虹脉冲)

## 9. Space-Time Call System (时空喊话系统)

### 9.1 System Overview
The Space-Time Call System enables cross-temporal and cross-spatial interactive messaging within the D-Music ecosystem. It supports multi-dimensional trigger mechanisms (time, location, event), multi-media message formats (text, voice, image, video, capsule), and encrypted privacy-first communication.

### 9.2 Core Message Types
| Type | Description | Use Case |
|------|-------------|----------|
| Text | Standard text messages with optional location | Quick fan interactions, comments |
| Voice | Audio recordings with waveform visualization and transcription | Emotional vocal messages, audio reviews |
| Image | Photos with filters and thumbnails | Visual storytelling, album art sharing |
| Video | Video clips with thumbnail previews | Performance clips, behind-the-scenes |
| Capsule | Time-locked message bundles with trigger conditions | Anniversary messages, delayed reveals |

### 9.3 Trigger Conditions
- **Time Trigger**: Messages are delivered at a specified future date/time (e.g., "Open on New Year's Day 2027").
- **Location Trigger**: Messages unlock when the recipient enters a geographic radius (e.g., "Unlock when within 100m of the concert venue").
- **Event Trigger**: Messages activate upon specific platform events (e.g., "Deliver when this song reaches 10,000 plays").
- **Manual**: Standard immediate delivery.

### 9.4 Space-Time Capsule
A capsule bundles multiple messages with a shared trigger condition. Key features:
- **Multi-contributor**: Multiple users can add messages to a shared capsule.
- **Auto-open**: The system continuously evaluates trigger conditions and automatically opens capsules when conditions are met.
- **Notification**: All contributors are notified when a capsule opens.

### 9.5 Privacy & Encryption
- Messages support AES-256-GCM encryption using the Web Crypto API.
- Privacy settings include: `public`, `private`, `friends`, `custom` visibility levels.
- Optional password protection with PBKDF2 key derivation (100,000 iterations).
- Configurable permissions: allow/deny replies, allow/deny forwarding.

### 9.6 Message Wall
Virtual location-based message boards where users can:
- Post anonymous or identified messages.
- Auto-moderation via AI content filtering.
- Theme customization (light/dark/custom).
- Moderator approval workflow for sensitive content.

### 9.7 Technical Stack
- **Real-time Communication**: WebSocket-based real-time message delivery.
- **Peer-to-Peer**: WebRTC for direct voice/data channels with STUN/TURN server support.
- **Audio Processing**: Web Audio API for waveform generation and audio duration analysis.
- **Speech-to-Text**: Automatic transcription of voice messages.
- **Geolocation**: Geofencing with Haversine formula for location-based trigger evaluation.

## 10. IP Matrix System (IP矩阵打造系统)

### 10.1 System Overview
The IP Matrix System provides a comprehensive framework for building, managing, and monetizing music creator identities (IPs). It covers profile management, content distribution, collaboration workflows, achievement systems, analytics, and incubator programs.

### 10.2 IP Profile Structure
Each creator IP profile includes:
- **Identity**: Name, category (musician/band/producer/DJ/composer/singer/songwriter), description, avatar, banner.
- **Social Links**: Verified platform connections (Spotify, Apple Music, YouTube, Instagram, Twitter, Website) with follower counts.
- **Metrics**: Followers, monthly listeners, engagement rate, total streams, revenue, growth trends, audience demographics.
- **Content Portfolio**: Tracks, albums, EPs, singles, videos, live recordings, merchandise, NFTs.
- **Collaborations**: Features, remixes, production credits, songwriting partnerships, brand deals.
- **Achievements**: Unlockable badges across categories (streams, followers, revenue, collaboration, milestones, special) with rarity tiers (common, rare, epic, legendary).

### 10.3 Content Rights Management
- **Ownership Tracking**: Owner, publisher, distributor chain of custody.
- **Licensing Types**: Exclusive, non-exclusive, sync, mechanical, performance licenses with territory and duration specifications.
- **Multi-Platform Distribution**: Status tracking (active/pending/removed) per platform with individual platform metrics.

### 10.4 IP Analytics Dashboard
| Analytics Layer | Metrics |
|-----------------|---------|
| Overview | Total streams, revenue, followers, engagement rate, growth rate, top content, top platforms |
| Content Performance | Per-content streams, revenue, engagement, trend direction, change percentage |
| Audience Insights | Demographics (age, gender, location, language), listening habits, engagement times, device usage, retention rate |
| Revenue Analysis | Breakdown by source (streams, downloads, sync, merch, live), projections with confidence scores, historical trends |
| Market Trends | Genre popularity, market share, growth rate, competition density |

### 10.5 IP Incubator Program
For emerging creators, the incubator program provides:
- **Eligibility Criteria**: Minimum followers, streams, content quality score, engagement rate, genre alignment.
- **Benefits**: Funding, promotion, mentorship, production resources, distribution partnerships.
- **AI Potential Assessment**: Automated scoring across base metrics, content quality, market potential, and growth trajectory to generate a SWOT analysis with estimated IP value, required investment, and projected ROI.

### 10.6 Distribution Channels
- **Channel Types**: Streaming, download, social, physical distribution.
- **Requirements**: Format specifications, quality standards, metadata completeness, rights verification.
- **Terms**: Revenue share percentages, payout frequency, exclusivity agreements, territory restrictions, duration contracts.
- **Performance Tracking**: Upload count, streams, revenue, engagement, last sync timestamp per channel.
