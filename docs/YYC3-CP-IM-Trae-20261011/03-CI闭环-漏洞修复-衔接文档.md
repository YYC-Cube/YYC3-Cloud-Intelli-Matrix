## 二、远程 CI 失败分析

失败运行：`37201770636`(CI/CD Pipeline)、`37201770708`(Deploy Pages)、Dependabot npm_and_yarn 多次。

**单一根因**：`pnpm-lock.yaml` 与 `package.json` 规格不同步，`pnpm install --frozen-lockfile` 在全部 Test shard / Quality / Pages Build 失败。不同步规格：

| 包 | lockfile | package.json |
| --- | --- | --- |
| @tailwindcss/vite | ^4.2.2 | ^4.2.4 |
| @vitejs/plugin-react | ^5.1.4 | ^6.0.1 |
| vite-plugin-electron | ^0.29.1 | ^0.28.0 |
| react-router | ^7.14.2 | ^7.13.1 |

次生问题：`pnpm-workspace.yaml` 含占位符（`allowBuilds: set this to true or false`）且 `ignoredBuiltDependencies` 错误忽略 electron。

## 三、修复措施

1. `git rebase origin/main`（本地 public 提交干净重放），备份分支留存。
2. 重写 `pnpm-workspace.yaml`：`allowBuilds`(pnpm 10.26+/11) + `onlyBuiltDependencies`(pnpm 9) 双键；overrides 与 package.json 逐字一致。
3. 全新解析生成 lockfile（删除旧 lockfile，pnpm 9 生成），消除陈旧 peer 解析（squirrel-windows/app-builder-lib 26.8.1 残留）。
4. release.yml 修复：删除覆盖 release notes 的 "Update release" 步骤；action-slack 无效 `webhook_url` → `SLACK_WEBHOOK` 环境变量；镜像旧名对齐。
5. PR Labeler 激活：新增 `.github/workflows/labeler.yml`(actions/labeler@v7)，对齐 `documentation` 标签名。
6. 仓库清理：解除跟踪 package-lock.json / *.tsbuildinfo（.gitignore 补规则）；删除 bunfig.toml、fix_fonts2.py。
7. 包名对齐 `yyc3-cloud-intelli-matrix`。
