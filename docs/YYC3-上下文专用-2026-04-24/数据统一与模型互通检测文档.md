### 3.2 跨组件数据流检测

```
场景1: 用户在SDKChatPanel发送消息
  SDKChatPanel → useBigModelSDK.sendMessage()
    → fetch(provider.baseUrl, { headers: buildAuthHeader() })
    → SSE流式解析
    → setMessages([...prev, assistantMsg])
    → saveStats(updatedStats)
    → saveSessions(updatedSessions)
  ✅ 数据流闭环

场景2: 用户在ModelProviderPanel添加模型
  ModelProviderPanel → useProviderSlice.addModel()
    → set({ configuredModels: [...prev, newModel] })
    → persist → localStorage自动同步
    → BroadcastChannel通知其他标签页
  ✅ 数据流闭环

场景3: 用户在InlineEditableTable编辑数据
  InlineEditableTable → onCellChange callback
    → buildUpdateSQL() 生成SQL
    → onExecuteSQL(sql) 执行
    → idbPut("committedChanges", changeRecord) 记录变更
    → toast.success() 反馈
  ✅ 数据流闭环

场景4: 用户在FamilyModelSettings绑定模型
  FamilyModelSettings → useFamilySettingsSlice.setMemberModelAssignments()
    → persist → localStorage
    → AIChatPanel读取 memberAssignment 路由到对应模型
  ✅ 数据流闭环
```

### 3.3 数据冲突检测

| 冲突场景 | 处理策略 | 实现 |
|---------|---------|------|
| 多标签页同时编辑 | BroadcastChannel → 最后写入胜 | getSharedChannel() |
| IndexedDB并发写入 | transaction原子性 | IDBDatabase.transaction |
| 模型切换中发送消息 | 队列化, 切换完成再发 | useBigModelSDK内部状态机 |
| 离线编辑冲突 | SyncConfig.conflictResolution | DatabaseAdapter |
