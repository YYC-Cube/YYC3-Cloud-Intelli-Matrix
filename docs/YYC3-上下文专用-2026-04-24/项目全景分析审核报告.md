## 九、全局基础设施

### 9.1 认证系统

```
登录流程:
  App.tsx → supabase.auth.getSession()
    ├── 3秒超时兜底
    ├── 成功 → AuthContext + RouterProvider
    ├── 失败 → Login页面
    │         ├── Email+密码登录
    │         └── Ghost Mode一键进入 (VITE_ENABLE_GHOST_MODE=true)
    └── 用户角色: admin / developer

Mock预设用户:
  admin@cloudpivot.local (admin)
  dev@cloudpivot.local (developer)
  ghost@yyc3.local (Ghost, admin权限)
```

### 9.2 实时数据流

```
WebSocket (ws://localhost:3113/ws)
  → useWebSocketData Hook
  → WebSocketContext.Provider
  → 全局共享: connectionState, reconnectCount, lastSyncTime
  → 消息类型: 节点状态/告警/吞吐量/系统统计
```

### 9.3 离线支持

```
PWA架构:
  Service Worker + IndexedDB
  → useOfflineMode Hook
  → useOfflineSlice (Zustand)
  → 离线数据同步队列
```

### 9.4 错误处理

```
4层Figma错误过滤:
  Layer 0: window.onerror (return true吞掉)
  Layer 0b: messageerror事件拦截
  Layer 0c: console.error静默
  Layer 1: window.addEventListener('error', capture)
  Layer 2: window.addEventListener('unhandledrejection', capture)

全局ErrorBoundary:
  level="page" → App级
  level="module" → 路由级 (withSuspense)
```
