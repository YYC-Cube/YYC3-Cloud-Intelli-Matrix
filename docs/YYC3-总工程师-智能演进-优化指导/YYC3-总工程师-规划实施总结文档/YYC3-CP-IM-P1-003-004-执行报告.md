## P1-003: 配置验证器实现

### 实施内容

#### 1. 创建 `config-validator.ts` 模块

**文件路径**: `src/app/lib/config-validator.ts`

**核心功能**:
- 使用 Zod v4 定义 APIEndpoints 验证 schema
- URL 格式验证（支持 http/https/ws/wss 协议）
- 相对路径验证（以 `/` 开头）
- 数值范围验证（timeout: 1000-300000ms, maxRetries: 0-10）
- 提供详细的错误信息和恢复建议

**导出接口**:
```typescript
export interface ConfigValidationResult {
  success: boolean;
  data?: APIEndpointsOutput;
  errors: ConfigValidationError[];
}

export interface ConfigValidationError {
  field: string;
  message: string;
  code: string;
  suggestion?: string;
}
```

**核心函数**:
- `validateAPIConfig(input)` - 完整配置验证
- `validatePartialAPIConfig(input)` - 部分配置验证
- `formatValidationErrors(errors)` - 格式化错误信息
- `getDefaultValue(key)` - 获取默认值
- `sanitizeAPIConfig(input)` - 过滤非法字段

#### 2. 集成到 `api-config.ts`

**文件路径**: `src/app/lib/api-config.ts`

**增强功能**:
- `loadConfig()` 加载时自动验证
- `setAPIConfig()` 更新时自动验证
- `setAPIConfigWithValidation()` 返回验证结果
- `validateConfigUpdates()` 预验证配置更新
- BroadcastChannel 消息验证

**新增接口**:
```typescript
export interface SetAPIConfigOptions {
  skipValidation?: boolean;
  silent?: boolean;
}

export interface SetAPIConfigResult {
  config: APIEndpoints;
  validation: ConfigValidationResult;
}
```
